# TankLoong v3.0.1 · 首个公开发行版

在声音里，找到你的频率。

TankLoong 是一款面向 Windows 的桌面音乐下载器，采用深色液态玻璃界面。先选择保存目录，再搜索歌名或歌手，选择歌曲即可下载并自动转换为 MP3。

## 功能

- 同时搜索咪咕、网易云、QQ 音乐、酷我、千千五个来源，结果陆续显示。
- 下载后自动转为 MP3，支持失败重试、同名自动编号及打开文件位置。
- 内置 Electron、Python 服务、musicdl 2.13.6 与 FFmpeg，无需额外安装运行环境。
- 保留 Chromium 默认沙箱与上下文隔离，包含最新版 Windows 启动修复。

## 下载与运行

1. 下载 `TankLoong-3.0.1-win-x64-portable.zip`。
2. 完整解压到本地文件夹，双击其中的 `TankLoong.exe`。
3. 选择歌曲保存目录，然后搜索和下载。

支持 Windows 10 / 11 x64。必须保留整个文件夹；单独的 EXE 无法运行。本版未签名，Windows 可能提示未知发布者。`SHA256SUMS.txt` 提供下载包校验值。

## 验证与限制

- 已验证发布包资源完整性、默认沙箱原生启动和界面交互；Node 测试 5 项通过。
- 先前完成 Python 测试 29 项及真实搜索、下载、MP3 完整解码验证；本次发布不代表重新验证所有平台或歌曲。
- 下载串行，搜索和下载记录仅保留当前会话。各平台接口可能变化，不保证所有歌曲可下载。
- 这是第一个 GitHub Release，版本沿用现有应用的 3.0.1。
